Set up Hubitat Home

A few steps and your dashboard is ready.

Setup code

Enter the SETUP_CODE you chose when you deployed. It stops anyone else from setting up your dashboard before you do.

Connect your hub

  1. Open your hub’s web page. In the left sidebar choose Apps, then Add Built-In App (newer hubs: Add App) → Maker API.
  2. Under Select Devices, tick the devices this app may use, then select Update. If you see an option for cloud / remote access, turn it on.
  3. Scroll to the example links. Under Cloud endpoints, copy the Get All Devices link (it starts with https://cloud.hubitat.com and ends with access_token=…) and paste it below. Then select Done on the hub.

Cloudflare runs in the cloud, so it needs the Cloud link, not the local (192.168…) one. Full guide with pictures: see the README on GitHub.

The token is stored only in your own Cloudflare account and is never sent back to any phone or browser.

Pick your devices

Tick what should appear in the app. You can rename tiles and group them into rooms (each room becomes a tab).

Location and time

Used for the outdoor temperature (Open-Meteo, free), day/night on the thermostat, and the time zone for plans and alerts. Rounded to about 1 km.

Features

Turn on what you want. Everything here can be changed later in Settings → House setup.

Alert rules

Get a phone alert when something is left on. Checked every 5 minutes on Cloudflare; each rule alerts once per on-period (or once per night).

Finish

Your private link unlocks the app. Anyone with it can control your devices, so keep it to yourself and your household.
